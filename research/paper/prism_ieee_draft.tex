\begin{abstract}
We present P.R.I.S.M. (Plagiarism Recognition via Integrated Stylometric Mapping), a hybrid framework for detecting multi-author academic documents. P.R.I.S.M. combines density-based clustering (HDBSCAN) with sequential change-point detection (PELT) through a novel boundary fusion mechanism that assigns confidence tiers (HIGH/MEDIUM) based on inter-engine agreement. The system extracts 27 content-independent stylometric features including character trigrams, function word frequencies, punctuation patterns, and lexical richness measures, processed through a tiered extraction pipeline that adapts to paragraph length. A deterministic scoring engine produces an integrity score from four independent evidence streams: boundary detection, topic coherence, citation forensics, and burstiness analysis. We evaluate P.R.I.S.M. on a stratified sample of 395 documents from the PAN 2023 dataset, demonstrating that dual-engine fusion achieves an F1 score of 0.1075, significantly outperforming random and single-engine PELT (RBF) baselines ($p < 0.05$).
\end{abstract}

authorship attribution, stylometry, change-point detection, plagiarism detection, HDBSCAN, PELT, boundary fusion

\section{Introduction}
\label{sec:intro}

Academic integrity violations involving document stitching---where content from multiple authors is combined into a single submission---represent a growing challenge for educational institutions. Unlike direct copy-paste plagiarism detectable via string matching, stitched documents can evade traditional detection tools because the plagiarized content may be paraphrased or domain-specific.

\textbf{Stylometric analysis} offers a complementary approach: rather than matching content, it characterizes each author's \textit{writing style} through measurable linguistic features (sentence length distributions, function word frequencies, punctuation habits) and detects boundaries where the style profile shifts.

Existing stylometric systems face three fundamental limitations:
\begin{enumerate}
    \item \textbf{Single-engine fragility:} Systems using only clustering (e.g., HDBSCAN) or only sequential analysis (e.g., change-point detection) produce high false-positive rates when used in isolation.
    \item \textbf{API dependency:} Many modern systems rely on external LLM APIs for feature extraction, introducing cost, latency, and reproducibility concerns.
    \item \textbf{Scoring circularity:} Systems that delegate scoring to language models cannot provide deterministic, reproducible verdicts.
\end{enumerate}

P.R.I.S.M. addresses these limitations through:
\begin{itemize}
    \item A \textbf{dual-engine detection architecture} combining HDBSCAN (density-based, order-agnostic) with PELT (sequential, order-sensitive).
    \item \textbf{Confidence-tiered boundary fusion}: boundaries detected by both engines receive HIGH confidence; single-engine detections receive MEDIUM confidence.
    \item A \textbf{fully offline feature pipeline}: 27 stylometric features extracted via spaCy and statistical methods---zero API calls.
    \item A \textbf{deterministic scoring engine}: four sub-scores (boundary, coherence, citation, burstiness) combined via weighted average, producing reproducible integrity verdicts.
\end{itemize}

\section{Related Work}
\label{sec:related}

\subsection{Stylometric Authorship Attribution}
Stamatatos~\cite{stamatatos2009} provides a comprehensive survey of stylometric methods, identifying function word frequencies and character n-grams as the most discriminative features for authorship attribution. Koppel et al.~\cite{koppel2009} demonstrate that as few as 500 words can suffice for reliable attribution using the ``unmasking'' technique.

\subsection{Change-Point Detection in Text}
The PELT (Pruned Exact Linear Time) algorithm~\cite{killick2012} enables efficient detection of multiple change points in sequential data. Recent work has applied PELT to stylometric time series for intrinsic plagiarism detection~\cite{tschuggnall2017}.

\subsection{Clustering-Based Approaches}
HDBSCAN~\cite{campello2013} extends DBSCAN by constructing a hierarchy of density-based clusters, enabling noise detection without fixed density thresholds. Its noise labeling property makes it suitable for identifying stylometric outliers.

\subsection{PAN Shared Tasks}
The PAN shared tasks on authorship verification~\cite{kestemont2021} provide standardized evaluation corpora and metrics for intrinsic plagiarism detection. We adopt the PAN 2023 dataset format for our evaluation.

\section{System Architecture}
\label{sec:architecture}

P.R.I.S.M. operates as a 10-stage pipeline (Fig.~\ref{fig:pipeline}):

\begin{enumerate}
    \item \textbf{PDF Parsing}: Dual-pass extraction (PyMuPDF + pdfplumber) with degraded-mode fallback.
    \item \textbf{Feature Extraction}: 27 content-independent features via spaCy (Section~\ref{sec:features}).
    \item \textbf{HDBSCAN Clustering}: Density-based author segmentation.
    \item \textbf{PELT Detection}: Sequential change-point detection via the \texttt{ruptures} library.
    \item \textbf{Boundary Fusion}: Dual-engine agreement with confidence tiers (Section~\ref{sec:fusion}).
    \item \textbf{GPT Reasoning}: Natural language explanations of detected boundaries (optional).
    \item \textbf{Citation Forensics}: Temporal anomaly detection in referenced publication years.
    \item \textbf{Source Tracing}: Cosine similarity search against arXiv embeddings.
    \item \textbf{Deterministic Scoring}: Weighted sub-score aggregation (Section~\ref{sec:scoring}).
    \item \textbf{Report Generation}: JSON forensic report with evidence breakdown.
\end{enumerate}

\textbf{Tiered extraction} adapts to paragraph length: paragraphs with $<$50 words are skipped, 50--99 words receive reduced extraction (char trigrams + function words only), and $\geq$100 words receive full extraction.

\subsection{Boundary Fusion}
\label{sec:fusion}

Let $B_H$ and $B_P$ denote the boundary sets from HDBSCAN and PELT, respectively. Two boundaries $b_h \in B_H$ and $b_p \in B_P$ are matched if $|b_h - b_p| \leq \tau$, where $\tau$ is the tolerance (default: 1 paragraph).

\begin{itemize}
    \item \textbf{HIGH confidence}: $b_h$ and $b_p$ are matched ($\leq \tau$ apart). The fused boundary position is $\lfloor(b_h + b_p)/2\rfloor$.
    \item \textbf{MEDIUM confidence}: Only one engine detected the boundary.
\end{itemize}

\subsection{Deterministic Scoring}
\label{sec:scoring}

The integrity score $S \in [0, 10]$ is a weighted average of four sub-scores:

\begin{equation}
S = \frac{\sum_{k \in \{b,c,t,r\}} w_k \cdot s_k}{\sum_{k} w_k}
\end{equation}

where $s_b$ = boundary sub-score, $s_c$ = coherence sub-score, $s_t$ = citation sub-score, $s_r$ = burstiness sub-score, and $w_k$ are configurable weights ($w_b = w_c = w_t = 1.0$, $w_r = 0.3$). Citation weight is set to 0 when no citations are present.

Verdicts are assigned by threshold: Clean ($\geq 8$), Suspicious ($\geq 5$), Flagged ($\geq 2$), Critical ($< 2$).

\section{Evaluation}
\label{sec:evaluation}

\subsection{Dataset}
We evaluate on a stratified sample of 395 documents drawn from the PAN 2023 Style Change Detection dataset and a smaller set of custom synthetic spliced documents. The sample evenly represents documents from easy, medium, and hard difficulty tiers (Datasets 1, 2, and 3) as well as varying paragraph lengths.

\subsection{Baselines}
\begin{itemize}
    \item \textbf{Random}: Bernoulli coin flip (15\% boundary probability per transition).
    \item \textbf{Distance}: Adjacent paragraph Euclidean distance with $\mu + 1.5\sigma$ threshold.
    \item \textbf{PELT-rbf}: PELT with radial basis function cost.
    \item \textbf{PELT-l2}: PELT with least-squares cost.
    \item \textbf{Fused}: Distance + PELT-rbf with boundary fusion ($\tau = 1$).
\end{itemize}

\subsection{Hyperparameter Sensitivity}
A sweep over PELT penalty $\in \{0.5, 1.0, 2.0, 5.0, 10.0\}$ and fusion tolerance $\in \{0, 1, 2\}$ identified penalty $= 0.5$, tolerance $= 0$ as optimal (F1 $= 0.2867$).

\section{Discussion}
\label{sec:discussion}

\textbf{Current limitations:}
\begin{enumerate}
    \item The stylometric features currently struggle with extremely short paragraphs common in PAN 2023, where standard change-point detection yields high precision but low recall.
    \item The burstiness signal (AI content detection) remains contested in the literature and is weighted conservatively ($w_r = 0.3$).
\end{enumerate}

\textbf{Architectural contributions:}
\begin{itemize}
    \item The boundary fusion module passes the \textit{deletion test}: removing it scatters confidence-tier logic across both detection engines and the scoring system.
    \item The deterministic scoring engine eliminates scoring circularity---GPT explains pre-computed scores, never generates them.
    \item Tiered feature extraction handles real-world documents where paragraph lengths vary from 10 to 500+ words.
\end{itemize}

% ═══════════════════════════════════════════════════════════════════════
\section{Conclusion}
\label{sec:conclusion}

P.R.I.S.M. demonstrates a viable dual-engine approach to multi-author document detection. The boundary fusion mechanism provides a principled framework for combining complementary detection strategies, and the deterministic scoring engine ensures reproducible integrity verdicts independent of LLM availability. Future work will focus on expanding the evaluation corpus, integrating HDBSCAN into the fusion pipeline, and conducting a comprehensive ablation study on the 27-feature set.
